# 交互契约

## 全局原则

- 操作反馈必须可定位、可关闭；需恢复操作的场景（如冲突重载、状态拉取/预览/校验重试）提供明确下一步动作按钮，其余错误提供排障提示。
- 保存、reload 和预览状态必须区分。
- 长耗时预览需要明确文案，不只显示 spinner。

## Modal

用于新增或编辑复杂条目。

- 居中显示。
- 表单校验在提交前完成基础格式检查。
- 取消不修改草稿。
- “应用到草稿”只更新草稿；顶栏“保存”统一写回配置与正文文件。

## Toast

用于操作结果反馈。

- 成功 Toast 3.6 秒后自动消失。
- 非持久信息/警告提示 8 秒后消失，错误提示默认持续显示（`persistent: true`）；同 `scope`（或无 `scope` 时同标题）的后续反馈替换旧提示，最多同时展示 3 条。
- 反馈正文不遮挡下方控件的点击；取消恢复操作后保留操作按钮。

## Confirm

用于删除条目、丢弃草稿、复制含 token 的订阅链接等高影响动作。

- 文案必须点名影响对象。
- 危险操作使用独立 danger 样式。
- 首次覆写已有本地 YAML 时必须提示注释、引号和格式风格可能丢失（本地主配置缺失首次创建文件时直接保存，不弹此确认）。

## Spinner 与禁用

- 触发中的主按钮显示 spinner 并禁用。
- 同一 mutation 不允许重复提交。
- 页面其他只读导航可以继续使用。

## 校验 Drawer

A8 诊断行提供“跳转”与“详情”两个独立动作：

- “跳转”直接按 `locator.json_pointer` 导航至目标页面并聚焦/高亮对应字段（无法匹配任何已知配置段时默认回退至 `/sources`）。
- “详情”打开右侧只读 `DiagnosticDrawer`，展示 `json_pointer`、`message`、`severity`、`code`、`display_path`、`section` 及“关闭 / 跳转字段”按钮（抽屉本身不提供内联编辑或重新校验）。

## revision warning

当存在未保存草稿（`isDraftDirty=true`）且 `status.config_revision` 与当前已加载 `baseRevision` 不一致时，顶栏展示 warning，不自动覆盖用户草稿，并提供“丢弃草稿”按钮回退至当前已加载基线。
